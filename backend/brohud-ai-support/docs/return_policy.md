# Return Policy

## Return Window

Customers can return products within **7 days** of receiving their order.

## Return Eligibility

Products must:

* Be unused.
* Have all original tags attached.
* Be in their original packaging.
* Be free from damage caused by the customer.

## Non-Returnable Products

The following cannot be returned:

* Used or washed clothing
* Gift cards
* Final sale items
* Customized products

## Return Process

1. Contact customer support with your Order ID.
2. Wait for return approval.
3. Pack the product securely.
4. Ship the product using the provided instructions.
5. Once received and inspected, the refund or exchange will be processed.

## Exchange

Customers may exchange the product for another size or color if stock is available.
